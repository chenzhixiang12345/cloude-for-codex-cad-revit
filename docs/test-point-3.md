# 结构合模测试清单

本轮先核对有明确原图依据的结构柱、梁和降板。阶段 4 的集中验收还在进行。

## 准备图纸和模型

1. 保留原始 A10、S50、S30、S40 DXF。使用对应 Revit 版本的签名包。安装步骤见[插件签名](revit-signing.md)。
2. 只测试板时，在空白项目点 **TuMo → 从 DXF 合并结构降板**。先选 A10，再选 S50。结构柱、梁与建筑的合模目前使用下面的命令行。把四个变量分别设为原始 DXF 的完整路径。在已解压的签名引擎目录打开 PowerShell。

   ```powershell
   .\tumo-engine.exe run $arch --merge-floors --structural-slab $slab `
       --structural-columns $columns --column-sheet S3009 `
       --structural-beams $beams --beam-sheet S4004 -o .\结构合模结果
   ```

3. 在输出目录保留 `model.json`、`issues.json` 和 `sources.json`。样例结果应有 26 个标高、42 条轴网、197 根柱、5087 面墙、391 扇门、229 扇窗、44 块结构板和 2 根结构梁。结构柱按共有轴网定位，3F 和 4F 的 KZ1 各替换一根同位置建筑柱。

## 在 Revit 核对

1. 打开本地合模 RVT。在项目浏览器双击 **3F**。对照原始 S3009，检查 KZ1 的位置和截面，尺寸应为 850×600 毫米。到 **4F** 核对同位置的 KZ1。3F、4F 结构柱底分别为 7750、10750 毫米，均比同层建筑标高低 50 毫米。
2. 在 **3F** 或三维视图选择 `KL29` 和 `KL3`。属性应显示结构框架类别，截面均为 200×1500 毫米。用剖面核对梁顶 8600 毫米、梁底 7100 毫米，再核对梁端与原图支座的位置。梁端自动连接仍待验收。
3. 在 **3F** 选择 `LB2` 和 `LB5`。建筑楼层为 7800 毫米。两块楼板的板顶分别为 7250 和 7700 毫米，厚度分别为 150 和 130 毫米。抽查附近的门窗和宿主墙。
4. 测试原生梁生成时，优先使用已载入矩形混凝土梁族的结构样板。建筑样板的本地族库缺少该族时，可先通过 **插入 → 载入族** 加入标准矩形混凝土梁族。查看器可验证建模和显示。保存、重开使用授权模式。

## 反馈

发现缺件、重叠或错层时，记录图号、楼层、构件编号或 `TuMo_ID`。附上 Revit 截图、生成日志和对应 `issues.json`。尚缺梁顶依据的梁候选、异形柱和边缘构件在疑点中核对。剪力墙和基础仍待接入。集中验收时需核查整套图纸的重复构件和冲突报告。
