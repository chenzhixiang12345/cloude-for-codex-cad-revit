# 建筑补全测试清单

使用对应 Revit 版本的签名安装包。安装方法见[插件签名](revit-signing.md)。先新建空白建筑项目。

## 检查建模入口

1. **从 DXF 生成模型**。选择 A10 建筑平面 DXF。检查 A1004 3F 的 42 条轴网、8 根柱、208 面墙、17 扇门及 10 扇窗。抽查 `WM0924A` 为 950×2400 毫米，`M0824A` 为 850×2400 毫米。
2. **从 DXF 生成标准层**。在另一份空白项目中选择相同 DXF。查看 3F、4F 和 24F。核对楼层表标高、独立构件编号和各层门窗的宿主。顶部标高为 R1F。
3. **从 DXF 合并楼层**。在另一份空白项目中选择相同 DXF。检查架空层、首层和二层是否与标准层的轴网对齐。完成弹窗会显示疑点报告目录。机房层和屋顶仍需按构件核对标高。检查生成模型可以一次撤销。
4. **从 DXF 合并结构降板**。在另一份空白项目中先选 A10 建筑 DXF，再选 S50 结构顶板 DXF。打开 3F，核对建筑楼层为 7800 毫米。选择 `LB2` 和 `LB5`，板顶应分别为 7250 和 7700 毫米，板厚为 150 和 130 毫米。共有轴网不吻合或已存在同层板区时，在疑点报告核对原因。

## 检查审图和原生构件

1. 运行 **从 DXF 审图**。缩放检查 CAD 矢量底图，以及有颜色和编号的轴网、柱、墙、门窗等。用疑点编号查阅 `issues.json`。A1004 可按坐标找到 42 处还需核对围合边界的房名和面积。
2. 用有明确信息的图纸检查房名和实际围合面积。检查楼板厚度、降板相对偏移和板洞的宿主。检查墙洞的宿主和构件编号。
3. 对照门窗表和立剖面核对窗台高。A1004 的 10 个窗位在疑点里有原图候选值。可见标注缺值时，插件暂用 900 毫米，并在日志中记录待核对。
4. 在授权模式保存 RVT，重新打开并检查几处代表性构件。若 Revit 处于查看器模式，可先验证生成和撤销。

测试点 2 还需补齐机房层、屋顶及其他缺少明确证据的真实构件。评分使用用户核对后的标准答案。F009 室内空间交付范围待确认。
