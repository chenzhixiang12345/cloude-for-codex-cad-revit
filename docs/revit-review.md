# 在 Revit 里审图

这个工具在独立的绘图视图里显示 CAD 底图和识别结果。底图是 DXF，可以在 Revit 里放大查看。

## 打开标准层

1. 安装与你的 Revit 年份相同的 TuMo 安装包。重启 Revit。如果出现“未签名的附加模块”，确认名称为“图模一致 TuMo”，确认来源后可选“载入一次”。
2. 用 Revit 自带的样板新建一个测试项目，或打开可编辑的测试项目。
3. 点击 `TuMo → 从 DXF 审图`。选择包含标准层的原始 DXF。
4. 关闭结果窗口后，Revit 会放大到本次识别的图框。也可以在项目浏览器的“绘图视图”里打开 `TuMo 审图 - 图号`。
5. 重新打开项目时，如果看到整套 CAD 图纸，把鼠标移到有彩色叠加线的图框上，用滚轮放大。底图是灰色，轴网是蓝色，柱是棕色，墙是绿色，疑点是红色十字。文字是识别编号。

## 核对和反馈

- 先选两处轴网交点，对比彩色线和灰色底图。再检查柱的大小和墙厚。
- 图面字太多时，按 `VG`，在“注释类别”里隐藏“文字注释”。可在“模型类别”的线条子类别里按类别隐藏审图线。可在“导入的类别”里隐藏 CAD 底图。
- 发现问题时，记录编号和问题。漏识别的位置可以截图圈出来。命令结束时会给出本地疑点报告的路径。
- 如果报告写着“结构墙轮廓仍有未建区域”，用疑点编号找到红色十字。对照该处的 CAD 边线和结构图标注，核对异形墙端或边缘构件。报告也保留了可在 CAD 中查找的图元句柄。
- 一次撤销可以移除本次创建的审图视图。重新运行会新建一个审图视图。生成原生模型仍使用“从 DXF 生成模型”。

## 直接导入矢量审图 DXF

1. 在测试项目新建一个绘图视图。
2. 点击“插入 → 导入 CAD”，选择导出的审图 DXF。启用“仅当前视图”。颜色选“保留”，图层选“可见”。首套样例使用毫米。
3. 导入后放大检查。以 `TUMO_REVIEW_` 开头的图层是识别线、编号和疑点。可用 `VG` 的“导入的类别”控制各图层。

开发命令可从识别后生成的 `model.json` 和同目录 `sources.json` 导出审图图纸。

```powershell
python -m tumo_engine.cli render-dxf out/model.json -o out/review.dxf
```
