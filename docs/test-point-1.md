# 测试点 1：安装并生成标准层

请分别在 Revit 2020、2024、2027 测试。有哪个版本就先测哪个，并记录版本号和内部版本号。

## 安装

1. 关闭 Revit。下载与 Revit 年份相同的 `TuMo-Revit-年份.zip`，解压到本地。
2. 在解压目录打开 PowerShell。运行下面的命令。

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
   ```

   安装地址在当前用户的 `%APPDATA%\Autodesk\Revit\Addins` 下。2020～2026 使用年份目录。2027 使用 `Revit 2027` 目录。
3. 打开 Revit。第一次出现加载确认时，检查名称是“图模一致 TuMo”，允许加载。功能区应出现 `TuMo` 标签。

## 生成和检查

| 操作 | 应该看到什么 |
| --- | --- |
| 从 Revit 自带的建筑或结构样板新建一个测试项目。保留项目的原文件。 | 项目可编辑，并有基本墙类型。 |
| 在 `TuMo` 标签点“从 DXF 生成模型”。选择一张标准层 DXF。 | 执行后出现标高、轴网、柱、墙的数量，以及输出目录和日志路径。 |
| 在项目楼层平面或三维视图中检查生成的构件。需要时用“缩放至合适大小”。 | 标高、轴网标签、墙中心线和柱位置与结果图对应。 |
| 量两处轴距、两处墙厚和两处柱截面。检查层高。 | 应与结果图和图纸尺寸相符。 |
| 放大墙与柱的连接处。 | 墙与柱正确接合，柱切墙。墙与墙的端部由 Revit 连接。 |
| 选中一面墙或一根柱，查看属性。 | `TuMo_ID` 和结果图编号一致。 |
| 按一次 Ctrl+Z。 | 本次生成的新对象一起撤销。 |
| 打开本次运行的日志。 | 有 Revit 版本、输入路径、耗时。出错时有详细异常。 |

自动生成柱族需要已安装的结构柱族样板，或者项目已有可匹配的结构柱族。正式项目宜从专用样板或用户已有样板开始。生成的墙类型和柱族用 `TuMo-` 开头，后面有截面尺寸，单位为毫米。

## 反馈

- 写明 Revit 年份、内部版本号和测试步骤。
- 错误示例：`W-0012 应为 200 mm`、`C-0003 与墙未连接`。
- 如果插件没有出现，发安装命令输出和 Revit 提示截图。
- 如果生成失败，发 `%LOCALAPPDATA%\TuMo\logs` 中本次的日志和问题截图。本次的模型与疑点报告在 `%LOCALAPPDATA%\TuMo\runs`。
